# Business Sales Performance Analytics

## Internship Task

Completed as part of the Data Science & Analytics Internship at Future Interns.

## Project Objective

Analyze business sales data to identify:

* Revenue trends
* Top-selling products
* Category performance
* Regional profitability

## Tools Used

* Power BI
* Excel

## Dashboard Features

* Total Sales KPI
* Total Profit KPI
* Sales Trend Analysis
* Top Selling Products
* Sales by Category
* Profit by Region

## Key Insights

* Technology category generated the highest sales.
* West region showed strong profitability.
* Sales showed growth over time.
* Some products performed significantly better than others.

## Recommendations

* Focus on high-performing products.
* Improve low-performing regional strategies.
* Increase focus on profitable categories.
